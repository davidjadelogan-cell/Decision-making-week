# Decision-Making Python Projects

This repository contains four beginner Python programs to practice decision-making using `if`, `elif`, and `else` statements and shows how they can be used to control program flow and make decisions based on user input.

---

## Projects Included

### 1. Age Validator
A program that checks a user's age and determines eligibility for a summer camp (summer camp 2026). It categorizes users into age groups or rejects them if they are not eligible.

---

### 2. Login Flow System
A simple registration and login system that validates user credentials. It checks password length during registration and verifies login details during authentication.

---

### 3. Loan Eligibility Checker
A program that determines whether a user qualifies for a loan based on:
- Age
- Employment status
- Monthly income

It uses conditional logic to approve or deny loan requests.

---

### 4. Expense Tracker
A budgeting program that calculates total monthly expenses and compares them to a spending limit (60% of monthly income). It flags users who exceed their limit.

---

## How to Run the Programs

Make sure you have Python installed on your system (Python 3.x recommended).

Run each file separately using your editor (e.g VS Code)
